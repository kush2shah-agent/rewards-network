# Rewards network

An interactive, sourced map of the U.S. travel rewards ecosystem. Snapshot: October 21, 2026.

61 nodes and 172 curated relationships. Distinguishes transfers, earning, shared balances, benefits, and co-branded cards. Includes a static no-JavaScript fallback and a touch-friendly mobile layout. No personal balances, login information, analytics, or external scripts.

Open index.html directly or serve it as a static site. Sources and eligibility notes are embedded in the page.
